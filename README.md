# 火候

陶艺窑炉烧成曲线编辑器。支持拖拽关键点调整目标温度与到达时间，自动识别升温、保温和降温阶段，按泥料与釉料规则检查升温速率、保温时长和降温速度，并导入记录仪 CSV 进行偏差比较。

## 烧成账（实测数据模型）

同一窑次停电断网后导出的多段 CSV 归并为该窑次唯一的一份「烧成账」：

- **分段记录**：每段 CSV 保留文件名、来源、导入时间与原始读数；按时间合并，重导同名文件只替换该段，不再整批替换实测。
- **人工校订优先**：班组长手工修正的温度按经过时间挂在账上，与分段读数重叠时覆盖读数；曲线编辑、偏差、风险、窑次对比全部读取同一份合并结果。
- **缺口单独保留**：段间或段内的停电断网区间自动识别为缺口，曲线断线、不插值补齐；缺口内的人工校订以独立点保留。
- **导入失败可重试**：解析失败时原账不动，文件内容与失败原因留档，修正后一键重试或放弃。
- **派生结果随账失效**：目标曲线、时间偏移或烧成账变化会改变结果签名，偏差、风险与对比立即失效重算，不再各存旧结果。
- **旧数据升级**：旧版平铺的 `actualSamples` 在加载时整体迁移为一段记录，并保留「旧账已迁移」标记，归并前后均可见来源与缺口。

```bash
corepack pnpm install
corepack pnpm dev
corepack pnpm build
```

所有窑次、模板和记录仪数据（含导入失败留档）均保存在浏览器本地。
